# Comp C — Opslaget

No picture at all. The page is one sentence at poster size — the sentence only these two could
say, that they will not quote before they have seen it — with a hard vertical rule down the
page and every practical fact living in the column on the other side of it. Mid stone-green
ground, no accent, ink only. It argues that the workshop's honesty is the offer.

- direction-version: 2.3
- composition: type alone at poster scale, split from the practical column by one hard vertical rule that runs the full height
- type: Petrona serif at display size over the same Petrona at reading size, one family throughout, figures in the same face
- colour: mid stone-green ground, neither light nor dark, ink only and no accent at all
- imagery: deliberately imageless — nothing is drawn, and the type carries the whole page
- rhythm: an asymmetric two-column field split by a single hard rule the length of the page

- surface: open space only — no rules between sections and no grounds; the one vertical rule is structure, not separation
- labels: marginal numerals — the five failures are numbered in the margin like clauses in a report, which is the register of the document the customer is buying
- figures: proportional — the price is set as a word in a sentence rather than as data, because there is only one number that matters here
- depth: overlap — a single hard offset shadow under the action, borrowed from painted shop signage, and nothing else layers

- visual-density: 4
- motion-intensity: 2
- aesthetic-boldness: 7
