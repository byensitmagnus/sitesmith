# Comp A — Rullen

The page is made of the same material as the product. A punched band of roll paper runs the
whole height, the text column sits beside it, and the first screen is a statement next to that
one object rather than an image of anything. It argues that the workshop is recognisable by the
thing it cuts, and that a person who has never opened a spool box can still see what a
perforation is.

- direction-version: 2.3
- composition: single drawn object beside a statement — a full-height perforated roll band with the text column set against it
- type: Fraunces serif display over IBM Plex Sans body, figures set in the body face
- colour: buff paper ground, one felt red reserved for the primary action
- imagery: diagram-led, drawn only — a punched band and a labelled cross-section, no photography
- rhythm: one continuous field with an asymmetric punched column running the full length

- surface: punched paper edges and changing paper grounds — the instrument reads a hole in paper, so a cut edge is the separator this subject already owns
- labels: sentence-case serif captions — the customer is a private person reading about a machine, and a caption that speaks like the body text does not add a second voice
- figures: functional tabular — the three prices are held against each other and nothing else on the page is a number, so tabular where compared and nowhere else
- depth: inset — the slots are holes, so the only layering on the page goes into the surface rather than above it

- visual-density: 4
- motion-intensity: 2
- aesthetic-boldness: 7
