## Notes against the columns

**source.** All four are drawn here. No photography exists for this subject and none can be
produced in this run — `EVIDENCE.md` §7 records that as a finding, and `DIRECTION.md` answers
it by declaring `imagery: diagram-led` rather than by leaving slots empty.

**licence.** `owned` in all four rows: original SVG and CSS authored for this page. No licensed
library, no stock, no generated imagery, so nothing needs an attribution rendered on the page.

**state.** All four are `ready`. There is no `needed` and no `substitute` row, because the
direction was chosen so that the assets it depends on could actually be made.

**treatment.** One treatment across both drawings: the same 1.6px ink stroke, the same `--void`
for anything punched, no fill anywhere else, and every rounded end at `--radius-full` because a
punched slot is the only place on the page where the shape carries the meaning.
