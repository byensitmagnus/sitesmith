# Aktivliste, Orgelværkstedet Hvidbjerg

Briefen oplyser, at der ikke findes fotografier. Der er derfor ingen på siden, og
der er ikke tegnet noget, som skal forestille et fotografi. Alt visuelt er CSS
eller skrift.

| `varighed-skala` | Måleskala over atten måneder med strækket fra otte til atten fyldt i bælgskind. Ren CSS, ingen billedfil, ingen SVG. ## Det, der ikke er på siden

- Ingen fotografier. Ingen er oplyst, og der bliver ikke opfundet nogen.
- Intet logo og intet bomærke. Afsenderen står som skrift i brevhovedet.
- Ingen ikoner. Ingen mærker, plaketter eller certificeringer af nogen art.
- Ingen udtalelser, ingen sognenavne, ingen instrumentnavne. Ingen er oplyst.
