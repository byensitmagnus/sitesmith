# Asset manifest

Damgaard Estrik is fictional and the brief forbids photography of it outright ("der
findes ingen billeder... lad ikke siden antyde at der findes fotos af denne
virksomhed"), a standing prohibition, not the ordinary "no photo supplied yet" gap. Per
`look.md` section 3, a physical subject with no photograph supplied is a draft; this run
ships `--draft` for that reason alone. Every visual element on the page is drawn.

## Why nothing else needed a row

Every other mark on the page is typography, CSS or table borders: the price table's
rules, the process list's numbered markers, the small circular mark beside the
sagsnummer on the Kvittering state. None of it stands in for a photographable thing.
`look.md` section 3 asks for a drawing where the answer is a diagram or a mark and
refuses one where the answer is a thing that exists and could be photographed; nothing
on this page claims to be the second kind.
