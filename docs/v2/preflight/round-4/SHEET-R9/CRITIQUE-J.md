- assets — Desktop screen 1: the Condition select is stretched to about 890px to hold the two words "Not checked" while the ullage figure, the number actually being recorded, gets a 115px box — the widths track available space, not importance. Mobile, "the consignment booked back in": the meta line breaks as "gyle 212 · ullage short · ullage / 11 pt", splitting a value across lines because the Undo link takes width out of the measure.

- direction — There is one and it is legible in the first screen: late first, then due today, with a counter strip above and a row you can complete without leaving the list. It is a competent reading of the job rather than a distinctive one.

The accent never appears where it does not carry state, and the refusal message (desktop state 1) deliberately does not use red so red keeps meaning "late" — that restraint is the best decision on the sheet.
