## 6. COMMITTED DIRECTION — “Movements Board”

### World

The console **is** a harbour **tide/movements chalkboard** mounted in a near-black night-watch shell. Fog-grey panel is the board face; light operational type is chalk. Ruled columns hold vessel · direction · time · berth note · status. Signal amber appears **only** for offline banner and validation error — never as brand flourish, never as nixie glow, never as gradient. No imagery, no logos, no KPI figures, no maps. Motion intensity 1: state change only, no decoration.

Colour strategy: **Restrained** (Operate default) forced by night-watch desk scene under dim indoor light → dark shell, quieter fog panels, single reserved amber fault signal.

### First viewport (desktop)

Full-width operational board — not a marketing hero, not a KPI dashboard.

1. **Thin status rail:** “Passage Log Console” · connection state (online default; offline → amber banner strip, operational wording only).
2. **Chalk-entry head strip (always visible, not a modal):**  
   - Vessel (required)  
   - Direction inbound \| outbound (required)  
   - Time / timestamp (required; defaulting behaviour **unknown** — do not invent auto-now claims)  
   - Berth note (job field; exact requiredness **unknown** beyond pack job wording)  
   - Primary control: **Save** with visible **Ctrl+Enter** hint  
3. **Board body (majority height):** dense chronological ruled rows — vessel · IN/OUT mark · time · note · status mark.
4. **States in-composition:**  
   - Empty log: quiet empty body under the entry strip (“No passages logged”) — no illustration  
   - Validation error: field-level + summary; amber only for error signal  
   - Success row: new row appears in chronological place; no confetti  
   - Offline banner: amber strip, short operational copy only

### Visitor path (harbour master)

Land on board → focus vessel field → fill required → Ctrl+Enter or Save → see success row on the board → ready for next entry without navigation.

### Signature interaction

**Chalk-entry head strip + Ctrl+Enter stamp** — the form is a permanent rewriteable first line of the movements board, not a separate page or wizard. Direction reads as short **IN/OUT** marks in the entry strip and on every row. That is the product-specific experience.
