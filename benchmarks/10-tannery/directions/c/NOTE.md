# Comp C — the statement

Type alone at scale. The first screen is one sentence set very large on a pale paper ground,
with no image, no drawing and no figure in it: *nine to fourteen months, nothing changes that*.
The argument is that the single most useful thing this firm can do for a buyer is set the
expectation about time before anything else is discussed, and that a statement only this firm
could make is a stronger first screen than any picture it does not own. The evidence arrives on
the second screen in wide alternating fields, and the plate of six leathers is a scroll away.

- composition: one sentence set at display scale, alone on the first screen, no image and no figure
- type: a grotesque sans at very large scale, tightly tracked, over the same sans for text
- colour: pale paper ground with no accent at all, black and one grey
- imagery: deliberately imageless above the fold, the statement is the object
- rhythm: wide alternating fields with hard rules between them
