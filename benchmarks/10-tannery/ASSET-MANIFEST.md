## Notes on the record

**Everything is drawn, and that is a direction rather than a shortfall.** There is no
photography of this subject, none exists to license, and there is no generation budget of any
kind on this build. `v2/25-assets.md` puts drawing fourth in its order of preference and says
it is *"often the strongest answer and it is under-used"* for subjects whose world is not
photogenic. The strongest true material here is twelve measured values and eight dates, and a
drawing is the only medium that can put six substances on one baseline.

**Two assets are not SVG files and one is not SVG at all.** `plate-sections` renders as six
inline `<svg>` elements, one per row, all carrying the same `data-asset` id, because the row
labels are HTML and have to reflow at 375 while the drawings stay on a shared scale.
`chart-pits` is HTML and CSS: a time axis that must reflow from 1440 to 375 without either
scrolling sideways or setting text at four pixels. It carries `data-asset="chart-pits"` on its
container so the record and the page can still be matched by hand, and it is a drawing in every
sense the plan means.

**Nothing here is `needed` or `substitute`.** There is no borrowed mark of any kind on this
page, at any state, because nobody has agreed to be named.

**Licence.** All five are original work made for this build. No third-party image, font file,
icon set or texture is loaded or embedded; the type is a system stack, and there is not one
external request on the page.
