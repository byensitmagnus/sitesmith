# Comp B — the promise, set large

The argument: the library's problem is not that people cannot find the seed, it is that they
do not understand the return. So the first screen is the promise and nothing else — six words
at 96px on an ink ground, then the number that proves the promise is not being kept. No
pictures at all: the type is the material. Sections are hard bands of alternating ground, so
the number lands in its own dark room.

- composition: type alone at scale, the promise filling the first screen, no imagery whatsoever
- type: condensed grotesque display over the system sans, figures set in the display face
- colour: dark ink ground, one gold accent carrying both the action and the figure
- imagery: deliberately imageless, the type is the material
- rhythm: alternating bands of two grounds
