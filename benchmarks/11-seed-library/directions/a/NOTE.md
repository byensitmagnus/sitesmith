# Comp A — the specimen sheet

The argument: the drawers *are* the content, so the page is the drawers. No hero at all. Under
a two-line masthead the nine seeds appear at once, drawn, at one scale, in a single frame, cut
in half by a hard vertical rule — five solid, four broken. A beginner can see the whole
holding and the whole easy/hard split before reading a word, which is the constraint the brief
sets. The ruled index starts immediately underneath, one entry per line with a hairline
between, in the manner of a seedsman's list. Because no photograph exists and none can be
taken, everything visual is drawn in line and ink, which is also the only honest option: the
seeds' real colours are nowhere in the verified set.

- composition: a drawn key of nine seeds at one scale across the top, split by a hard rule, with the ruled index starting immediately beneath
- type: old-style serif display over the system sans, figures in monospace
- colour: buff paper ground, one stamp red reserved for the return
- imagery: diagram-led, ink line drawings, solid when the seed comes back true and broken when it does not
- rhythm: one continuous paper field, sections separated by a single hard rule
