# Direction B — the printed tide table

The argument: this is a tide table, so set it as one. No chart at all. Paper ground, a serif
head over columns of monospaced figures, the windows given as clock times in aligned columns
exactly as an Admiralty table prints them, and the sections divided by banded grounds the way a
printed page separates its tables. The claim is that an expert reads figures faster than a
picture of figures, and the picture is what makes a dashboard a dashboard.

- composition: a dense index that starts immediately, type alone at scale, no drawn instrument
- type: a serif display over monospaced figures
- colour: paper ground, one ink and one red for a shut lock
- imagery: deliberately imageless
- rhythm: alternating bands, one per table
