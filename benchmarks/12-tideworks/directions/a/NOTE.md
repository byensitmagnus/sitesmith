# Direction A — the shared ruler

The argument: the tide is one thing and every lock hangs off it, so the board draws **one time
ruler** and lays the six locks across it as lanes. The part of each window that is already gone
is a thin line; the part still to come is solid. A keeper reads the solid lengths at a glance
and knows the order they will lose them in. Everything else on the page is a ruled column under
that instrument, on one continuous near-black field, set in a single monospace so that no
column of times ever shifts under its own digits.

- composition: a 48px chrome bar, one status line, then a six-lane shared time ruler full width above the ruled tables
- type: one monospace throughout, figures tabular by construction
- colour: near-black continuous ground, signal green reserved for a window still open
- imagery: deliberately imageless, the windows drawn in CSS as data
- rhythm: one continuous field, sections separated by full-width hairline rules
