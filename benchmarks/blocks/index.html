scrollable-grid

Use
A table wider than the column it sits in. Any admin, report or queue.
Avoid
Fewer than five rows, or content that reflows happily, use a definition list.
Prevents
A horizontal scroller no keyboard can reach (axe: scrollable-region-focusable); visually-hidden labels escaping the clip and setting document width from inside the grid; a parent 1fr track widening instead of the child scrolling.

empty-state

Use
Any list, table or panel that can legitimately have nothing in it.
Avoid
A loading state, that is a different component and a different message.
Prevents
The state every generated page forgets, and the one every real product hits on day one. Also the empty state that says "No data" and offers no way out, which is a dead end wearing a sentence.

error-summary

Use
Any form that can fail validation on more than one field.
Avoid
A single-field form, put the message on the field and stop.
Prevents
Errors a screen-reader user meets one field at a time with no way back to the first; a field whose message is not wired to it by aria-describedby; and a focus ring that differs per control, so it has to be relearned.
