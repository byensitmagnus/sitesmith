# Direction A — the counter

The specification table *is* the page. There is no hero, because a chandler arriving here
already knows they want rope and is choosing between constructions. The drawing sits in the
first column of each row at the size the eye needs to tell a lay from a braid, so the
comparison the buyer is actually making happens inside the table rather than beside it.
Warm paper ground and a condensed face, taken from the printed catalogue this trade already
uses. The one saturated colour on the page is a stamp red, and it appears once, on the
sentence about safe working loads.

- composition: dense index starting immediately, no hero
- type: condensed sans with tabular mono figures
- colour: warm paper ground, one stamp red used once
- imagery: diagram-led, drawings inline in the table at row scale
- rhythm: one continuous field divided by hairlines
