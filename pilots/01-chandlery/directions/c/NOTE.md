# Direction C — the ticket

Split down a hard vertical rule: the cut ticket on the left, the specification on the right,
with the total the only large figure on the page. The argument is that the transaction here
is unusual — you buy a length, not a unit, and the price is not knowable until you say how
long — so the calculator should be the page rather than a control at the bottom of it.

Deliberately imageless apart from the mark. That is the choice being tested: whether a page
about rope can carry itself on figures alone.

- composition: split on a hard vertical rule, calculator left
- type: system sans, few sizes, mono for every figure
- colour: light neutral ground, one green accent on the action
- imagery: deliberately imageless, figures only
- rhythm: asymmetric column running the full height of the page
