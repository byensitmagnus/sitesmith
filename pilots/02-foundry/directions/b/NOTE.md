# Direction B — the inscription

The lettering is the object. A bell's inscription is cast to be read from thirty feet below
in bad light, which is a real constraint on letterform and spacing, and the page is set as if
it were the waist of a bell: wide capitals, generous tracking, centred, nothing else on the
screen.

Limewash white, from the ringing chamber rather than the foundry floor.

- composition: type alone at scale, centred
- type: wide cast capitals as the only display, no figures
- colour: limewash white ground, ink, no accent
- imagery: deliberately imageless
- rhythm: one continuous field, centred
