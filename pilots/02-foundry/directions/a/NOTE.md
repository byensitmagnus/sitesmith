# Direction A — the profile

The half-section runs the full height of a sticky left column, so the drawing is present for
as long as the reader is on the page rather than appearing once and scrolling away. The
argument is that a bell cannot be photographed usefully and the profile is the only view in
which a founder's work is visible at all, so the profile should be the page furniture.

Near-black ground with bell metal, because that is what a bell looks like in a tower with one
window — and because the drawing is a line drawing, which needs a dark ground to read as a
plate rather than a diagram.

- composition: full-height drawing in a fixed column, text scrolling beside it
- type: wide cast-inscription capitals over a system sans, mono for figures
- colour: near-black ground, bell metal, no second accent
- imagery: object-led, one drawing at full column height
- rhythm: asymmetric column running the whole page
